# Projeto — Otimização de Produto Matricial

O enunciado está em `Projeto_Implementacao_Produto_Interno.md`; a entrega
completa está no diretório `trabalho_pratico/` (código C, Makefile, scripts de
benchmark/coleta e artefatos por máquina). Consulte
[`trabalho_pratico/README.md`](trabalho_pratico/README.md) para instruções de
compilação, execução e medição.

Atalho: qualquer alvo do pacote pode ser invocado da raiz, por exemplo
`make`, `make bench REPS=1` ou `make entrega`.
